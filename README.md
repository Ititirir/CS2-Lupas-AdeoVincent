# Electricity Bill Calculator

A Python program, with the sole purpose of calculating one's electricity bill.

## How to Run
1. Download {FILENAME}.py
2. Make sure to have Python/IDLE Shell/a program that can run Python files installed
3. Run the program by double-clicking the file
4. Enter required information.

## Version 1 - Original code w/o input validation
- Input: Accepts customer name and electricity reading.
- Process: Calculates and displays the estimated bill.
- Output: Estimated bill.
- Absolutely NO input validation.
